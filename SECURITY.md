# Security Policy

## Reporting a vulnerability

Please report security issues privately through
[GitHub Security Advisories](https://github.com/sgash708/skillctl/security/advisories/new)
rather than opening a public issue.

## Scope

skillctl runs the `claude`, `codex` and `gh` CLIs and installs plugins from the repository you point it at. What those plugins contain is up to their authors and outside the scope of this project. Only import from repositories you trust.
